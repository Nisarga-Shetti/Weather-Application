# Weather Application

A responsive weather application built using HTML, CSS, and JavaScript. It allows users to search for a city and view its current weather information using the Open-Meteo API.

## Features

- Search weather by city name
- Current temperature in Celsius
- Weather conditions and icons
- Humidity
- Wind speed
- Feels-like temperature
- Enter key search support
- Invalid city error handling
- Responsive design

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Open-Meteo Weather API
- Open-Meteo Geocoding API

## API Used

Open-Meteo: https://open-meteo.com/

Geocoding API: https://geocoding-api.open-meteo.com/

## How to Run

1. Clone the repository.
2. Open the project folder in VS Code.
3. Run `index.html` using Live Server.
4. Enter a city name and click Search.
5. View the current weather information.
